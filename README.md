# Dotfiles

This is a directory of all the files for configuring my arch pc. These are custom configs for myself so I am not responsible for breaking changes and i will not be announcing it prior to updating these files. Use at your own discretion.

# Installation

```bash
git clone https://www.github.com/Adnan-Malik-26/dotfiles
cd dotfiles
./install.sh
```

# Usag

The installation script installs all the files and sets up symlinks for all your config directories inside of `$HOME/.config`
